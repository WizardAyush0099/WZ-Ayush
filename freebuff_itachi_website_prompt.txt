Build a premium, cinematic, animation-heavy portfolio/creative website inspired by the interaction quality and visual storytelling of https://manndamani.com/ — but DO NOT copy its branding, text, assets, layout pixel-for-pixel, or source code.

The website should feel like an interactive anime cinematic experience centered around ITACHI UCHIHA from Naruto. The main focus is the hero animation and scroll experience.

IMPORTANT:
This is NOT a normal portfolio template. Motion, depth, image transitions, parallax and cinematic storytelling are the core of the website.

========================
1. OVERALL VISUAL DIRECTION
========================

Create a dark cinematic visual language:

- Near-black background
- Deep crimson/red accent lighting
- Dark maroon gradients
- Subtle off-white typography
- Very subtle film grain/noise
- Soft atmospheric fog/smoke
- Red particles/embers
- High contrast imagery
- Premium editorial typography
- Lots of intentional negative space
- No cheap neon cyberpunk look
- No excessive glowing UI
- No generic anime dashboard/card design

The website should feel like a high-end creative studio website combined with an anime film sequence.

Use smooth animation throughout the entire page.

Preferred technologies if supported:
- GSAP
- ScrollTrigger
- Lenis or another smooth-scroll system
- CSS transforms
- requestAnimationFrame where appropriate
- WebGL/Three.js only where it genuinely improves the effect

Keep performance high and avoid unnecessary libraries.

========================
2. HERO — ITACHI CINEMATIC EFFECT
========================

THIS IS THE MOST IMPORTANT SECTION.

Create a full-screen 100vh cinematic hero.

Background:
- Almost completely black
- Very subtle dark-red atmospheric gradient
- Moving smoke/fog
- Tiny floating red particles
- Very subtle film grain
- No distracting background UI

Main visual:
Place a high-quality Itachi Uchiha image/render in the center/right area.

The Itachi image must NOT simply sit as a normal static PNG.

Create multiple visual layers:

1. Background atmosphere
2. Large blurred Itachi silhouette/shadow
3. Main Itachi figure
4. Foreground particles
5. Red light effects
6. Optional subtle feather/crow particles
7. Depth layers

Create a convincing 3D/parallax effect.

When the mouse moves:
- Itachi subtly moves in the opposite/related direction
- Background moves slower
- Foreground particles move slightly faster
- The character has subtle depth
- Do NOT overdo the movement

On mobile:
Use device orientation if available, otherwise use gentle touch movement.
Do not create an annoying movement effect.

========================
3. SHARINGAN / EYE EFFECT
========================

Create a subtle cinematic Sharingan-inspired effect around/behind Itachi.

Do NOT make it look like a cheap glowing circle.

It should appear gradually as the user interacts with the hero.

Possible sequence:

- Initially almost invisible
- Small red glow appears
- Circular pattern slowly forms
- Subtle rotation
- Red light pulse
- Very subtle particles move around it
- Effect fades into the background

Keep it elegant and cinematic.

When the user moves the cursor toward the hero, slightly increase the intensity.

Do not use excessive red bloom.

========================
4. ITACHI EYES / MANGEKYO EFFECT
========================

Add a subtle eye-light animation when the hero becomes active.

The effect should feel like Itachi's Mangekyo Sharingan activating.

Animation:

almost invisible

very subtle red eye glow

scroll:
brief cinematic activation

Do NOT constantly flash the user's screen.

Use smooth opacity and blur transitions.

========================

"ITACHI"

Animate this indicator subtly.

========================
6. HERO SCROLL EXPERIENCE
========================

When the user begins scrolling:

DO NOT immediately jump to the next section.

Create a cinematic transition.

As scroll progresses:

- Hero zooms slightly
- Itachi becomes larger
- Background darkens
- Red particles increase
- Character slowly moves
- Typography moves independently
- Sharingan effect briefly becomes stronger
- Smoke passes across the screen
- Hero gradually transitions into the next section

Use GSAP ScrollTrigger or equivalent.

The animation must be tied to scroll progress rather than simply playing once.

Make the transition smooth and reversible when the user scrolls upward.
